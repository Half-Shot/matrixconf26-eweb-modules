    Interface X509ApiAlpha

    Hardware-key signing with an X.509 certificate, backed by Element Desktop's main process.

    On configured builds of Element Desktop Pro, this is exposed as window.electron.x509, with one method per command on the x509 IPC channel. The module API hands this same object to modules.
